# 光模块结构探索器

一个用于展示 400G 至 3.2T 光模块不同型号、技术路线、组成部件和参考单价的静态交互式 demo。

## Demo 内容

- 按总速率、Host/Optical 通道组织、光源路线和具体型号逐步筛选。
- 查看不同光模块型号的 2D 产品结构图。
- 点击结构图热点或左侧器件树，查看器件层级、功能、关键指标、参考价格区间、用量和来源边界。
- 支持 TX/RX 路径切换、器件搜索、器件类别过滤和来源弹窗。

## 本地运行

这个 demo 是单文件静态网页，不需要安装依赖。

```bash
open index.html
```

也可以用任意静态文件服务器打开：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 数据边界

- 产品结构图为基于公开资料整理的代表性工程示意，不代表某一厂商特定 SKU 的精确拆机图。
- 整体模块与器件价格来自公开目录价、行业参考 ASP 或估算区间，不等同于厂商正式报价。
- 光栅、谐振腔及 PN 结等无法独立采购的微结构，其成本计入所属器件。
- 供应商信息表示公开产品能力或生态覆盖，不构成具体供货关系确认。
