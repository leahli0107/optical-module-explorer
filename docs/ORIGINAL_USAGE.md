# 光模块结构探索器交付包

## 文件内容

- `光模块400G-3.2T架构与器件数据库_v3_20260823.xlsx`：网页使用的数据底稿，包含架构、器件、BOM、价格区间、供应商和来源等信息
- `光模块结构探索器_400G-3.2T_v3_产品结构.html`：可离线打开的完整网页

## 使用方式

- 离线查看：解压后双击HTML文件，使用Chrome、Edge或Safari打开
- 在线查看：https://anthonyhanxiangding-lab.github.io/optical-module-explorer/
- 网页为单文件静态应用，不需要安装软件或启动服务器

## 数据边界

- 产品结构图为基于公开资料整理的代表性工程示意，不是某一厂商特定SKU的精确拆机图
- 整体模块与器件价格为公开目录价格、行业参考ASP或估算区间，不等同于厂商正式报价
- 光栅、谐振腔及PN结等无法独立采购的微结构，其成本计入所属器件
- 供应商信息表示公开产品能力或生态覆盖，不构成具体供货关系确认
